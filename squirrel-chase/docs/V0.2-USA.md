# Pip's Squirrel Chase v0.2: the USA Tour (build contract)

Why: one case a day and six cases; daily players have run out. v0.2 makes the locked `usa` arc playable: six cases across the
United States on a new US map. SPEC.md and docs/CONTENT-GUIDE.md still hold; this file adds to them. Every kid rule
(CONTENT-GUIDE "Kid rules", SPEC) applies unchanged: content is read silently, only the child's own spelling words, their
sentences, the letters and the hideout sentence are voiced.

## 1. Shared interfaces (all three agents build to these exactly)

**Projection** (`src/content/geo.js`, content agent adds; art and app import):

```js
export const US_MAP_BOUNDS = Object.freeze({ west: -125.0, east: -66.5, north: 49.6, south: 24.2, aspect: 1.83 });
// aspect: 58.5 deg wide x 25.4 deg tall, a degree of longitude ~0.79 of latitude at 37.5 N -> true shape ~1.83 : 1
export function toUsMap(lat, lng) // -> { x, y } in 0..1, same formula and rounding as toMap, on US_MAP_BOUNDS
```

**City**: new field `usCoords: { x, y }` (= `toUsMap(latLng)`), present on every city that a `usa` case uses and absent on
the others. `coords` (NY box) stays as is; new non-NY cities get `coords: null`.

**Arc**: new field `map: 'ny' | 'usa'`. `ny` arc gets `map: 'ny'`; `usa` arc gets `map: 'usa'`, a new blurb, and cases
`usa-01` … `usa-06`.

**The USA tour cities** (ids fixed now so the art can be drawn in parallel; the content agent uses exactly these 12):

New York focus: the tour starts in New York City (Scrabble "just bought a map of the whole country") and the finale comes
home to New York City.

**Map API** (art agent): `drawMap(el, { cities, highlight, visited, arc })`: `arc: 'usa'` draws the US map and places pins
from `city.usCoords`, skipping cities without it; `arc: 'ny'` (default) is unchanged and skips cities with `coords: null`.
Same return value `{ svg, pins, update }`, same pin buttons and keyboard behavior.

## 2. Content agent

- 11 new cities with 3-4 verified facts, a generic landmark `sign` (capitals, no brands/logos), a `scene` line, and 6+
  clues each that never name the city and point to exactly one tour city (extend `tools/content/signatures.mjs`; the
  NE corridor cities share history, so every clue needs its unique detail). Add `usCoords` to New York City and 6+ clues
  for it that work on a US-wide trip if its current clues lean on NY-only geography.
- Six cases following the NY recipe: a different lead and sign each time, 3-4 stops, two respectful witnesses per stop,
  the Chief's running gag continues (new wrong names; finale he gets it right), the finale (usa-06) has the whole gang and
  ends in New York City. Distances are big now: witnesses may mention flying.
- Sources: NPS, Smithsonian, NASA, city and state government, museums, Britannica, visitor bureaus. Every claim in a "USA
  Tour" section of `docs/SOURCES.md`. Update CONTENT-GUIDE's tables. `tools/content-tests.mjs` passes and checks the new
  arc (routes, clue → next city, ambiguity, usCoords present for every usa-route city, kid-rule words, reading level).

## 3. Art agent

- The US map: contiguous 48 states in the `US_MAP_BOUNDS` box at aspect 1.83, a clean recognizable outline, light state
  lines, the Great Lakes, Gulf and both coasts; **New York State highlighted** (the home state); same style, palette, pins
  and labels as the NY map. Tap targets stay usable at 390px wide; the NE cluster (Boston / New York City / Philadelphia /
  Washington) is the tight spot: label placement must not collide (the app already has a zoom-in list for close pins).
- 11 new postcard scenes (keys in the table) in the existing `scenes.js` style, added to `SCENES`, `SCENE_ACCENT` and
  `sceneKey()` (keep `new-orleans` from matching anything else). Generic landmarks only: no logos, team marks or brands.
- Plane travel art exists; check it reads well for long hops.
- Update `src/art/README.md` and the art gallery page.

## 4. App agent

- The `usa` arc is unlocked and playable. Pacing runs NY then USA: a save with all six NY cases closed (the "done" state)
  opens `usa-01` on the next local day with no parent action; logic test for exactly that.
- Every map (home, travel, case board) is drawn with the arc of the case in play (`arc: arc.map`), and lists only that
  arc's cities; the close-pins zoom-in list works on the US map. Travel between US cities uses the plane.
- Case board / home shows both tours (NY with its stamps, USA next). The album groups postcards by tour.
- Lab summary line names the current tour (`NY tour: n / 6`, then `USA tour: n / 6`), never a countdown.
- Anything else that assumes one arc or the NY map (search `src/`): make it arc-aware.
- Tests: logic-tests, ui-smoke (add a small `usa` arc + cities with `usCoords` to `tools/fixtures` so the map switch, plane
  and album grouping are exercised), sync-smoke, content-play (plays every real case; extend it to usa-01..06; it will
  only pass once content lands — write it and say so). Version **0.2.0** (sw.js cache, main.js, README changelog).

## 5. File ownership

- Content agent: `squirrel-chase/src/content/**`, `docs/SOURCES.md`, `docs/CONTENT-GUIDE.md`, `tools/content-tests.mjs`,
  `tools/content/**`.
- Art agent: `squirrel-chase/src/art/**`, `tools/art-gallery.html`. It may read content but must not edit it.
- App agent: everything else under `squirrel-chase/` (src/ui, src/logic, src/meta, src/main.js, style, sw.js, README,
  other tools, fixtures). Not `src/content/**` or `src/art/**`.
- Nobody edits other games, `lab/`, or shared `/spell-jump/src/` modules.
